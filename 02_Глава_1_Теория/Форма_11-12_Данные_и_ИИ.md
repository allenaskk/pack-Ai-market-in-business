# Формы 11-12. Данные, аналитика и ИИ

## Форма 11. Путь данных на рынке

| Шаг | Что происходит | Инструмент или поставщик | Слабое звено |
| :--- | :--- | :--- | :--- |
| **1. Источники** | Клиент пишет в чат или звонит | Naumen Erudite (канал приема) | Данные в разных форматах (текст + голос) |
| **2. Хранение** | Обращения сохраняются в базе | PostgreSQL (в составе Naumen) | 152-ФЗ ограничивает хранение в облаке |
| **3. Обработка** | Текст очищается, размечается | Python, Java (среда Naumen) | Ручная разметка долгая, ошибки ломают модель |
| **4. Аналитика и BI** | Строятся отчеты по обращениям | Naumen + Visiology / Форсайт | Без качественных данных аналитика показывает мусор |
| **5. Решение** | Руководитель решает расширить бота | Руководитель клиентского сервиса | Решение принимается без учета слабых мест |

**Где применяется ИИ:** Шаг 3 (обработка) и шаг 4 (аналитика). NLU-модели размечают текст, LLM генерируют ответы. Зависит от слоя «Данные и аналитика».
