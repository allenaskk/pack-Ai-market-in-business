# Формы 8-9. Технологическая платформа и зависимость

## Форма 8. Технологическая платформа (Naumen Erudite)

| Слой | Что использует продукт | Основной поставщик | Альтернативный поставщик |
| :--- | :--- | :--- | :--- |
| **Сеть и доступ** | Каналы связи, телефония | Ростелеком, МТС | Мегафон, Билайн |
| **Устройства** | Серверы, телефоны клиентов | Naumen (ЦОД) / заказчик | Yandex Cloud, Cloud.ru |
| **Вычисления и хранение** | Виртуальные серверы, хранение диалогов | Naumen (облако) / заказчик | Yandex Cloud, VK Cloud |
| **Платформенное ПО** | Linux, PostgreSQL, Java, Docker | PostgreSQL, Java, Docker | Astra Linux, Postgres Pro |
| **Данные и аналитика** | Хранение диалогов, дашборды | Naumen + заказчик | Visiology, Форсайт |
| **ИИ** | ASR (речь), TTS (синтез), NLU, LLM | Naumen (свои) + сторонние LLM | MWS AI, Just AI, ЦРТ, YandexGPT |

## Форма 9. Зависимость и стоимость переключения

| Вопрос | Слой А (ИИ + Данные) | Слой Б (Вычисления) |
| :--- | :--- | :--- |
| **Что можно заменить** | Модели Naumen на MWS AI / Just AI / ЦРТ / YandexGPT | Облако Naumen на Yandex Cloud / VK Cloud |
| **Во что обойдется замена** | Перенести диалоги, переобучить модели, настроить интеграции | Перенести серверы и базы данных, проверить безопасность |
| **Оценка** | Месяцы (3–6 мес.) | Недели (2–4 нед.) |
| **Регулирование** | 152-ФЗ, реестр ПО | 152-ФЗ, Указ №166 (КИИ) |

**Почему слой А дороже:** Данные и модели настраивались под конкретный банк. Инфраструктуру менять проще — это стандартная услуга.
