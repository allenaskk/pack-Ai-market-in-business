# Форма 15. Сверка и аудит реестра

## Часть А. Аудит реестра
| Показатель реестра | Значение | Норма | Выполнено (да/нет) |
| :--- | :--- | :--- | :--- |
| **Всего источников** | 20 | ≥20 | Да |
| **Источников последних двух лет (2024–2026)** | 17 из 20 = 85% | ≥30% | Да |
| **Источников с указанным периодом данных и методикой** | 20 из 20 | все | Да |
| **Типов источников** | 6 (международные, российские, статистика, реестры, пресса, вендоры) | ≥3 | Да |
| **Российских и зарубежных источников** | 18 российских + 2 зарубежных | есть оба вида | Да |
| **Источников вендоров** | 5 из 20 = 25% | ≤30% | Да |

## Часть Б. Сверка показателя (объём рынка ИИ в РФ)
| Параметр | Источник А (TAdviser) | Источник Б (CNews) |
| :--- | :--- | :--- |
| **Показатель** | Объём рынка Big Data + ИИ | Выручка от ИИ-проектов |
| **Значение и единица** | 430 млрд руб. | 75,6 млрд руб. (топ-15) |
| **Период** | 2024–2025 | 2025 |
| **Охват** | Big Data + ИИ + консалтинг | Только ИИ-проекты 60 компаний |
| **Методика** | Опрос, расчёт | Рейтинг по выручке |
| **Кто заинтересован** | Независимое агентство | Независимое агентство |

**Причина расхождения:** разные границы продукта (Big Data + ИИ vs только ИИ) и разный охват (весь рынок vs 60 компаний).

**Какое значение использую в КР:** 430 млрд руб. с оговоркой «широкий рынок Big Data и ИИ».

**Вывод по форме:**
Показатель «объём рынка ИИ в РФ» за 2025 год оценивают по-разному: TAdviser — 430 млрд руб. (Big Data + ИИ + консалтинг), CNews — 75,6 млрд руб. (выручка 60 компаний от ИИ-проектов). Расхождение объясняется разными границами продукта и охватом. В работе используется 430 млрд руб. с оговоркой, что это широкий рынок, потому что он охватывает больше участников.
