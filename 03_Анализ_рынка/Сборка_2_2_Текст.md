# Сборка п. 2.2: первая связная версия (MVP)

**Абзац 1. Позиция и граница**
Анализ среды выполнен для вендора (компании Naumen) на рынке решений искусственного интеллекта для бизнеса в РФ в границах: ПО для ИИ, потребители — российские организации B2B, территория — РФ, период — 2024–2026 гг. Все факторы ниже оцениваются с позиции вендора.

**Абзац 2. Макросреда**
Из 8 факторов макросреды (форма 19) для позиции вендора наиболее значимы рост рынка GenAI (балл 25), госстратегия ИИ до 2030 (балл 20) и требования 152-ФЗ (балл 20). Рейтинг устойчив: при изменении оценок на 1 балл первая тройка не меняется (форма 20).

**Абзац 3. Отраслевая среда**
В отличие от макросреды, отраслевые силы распределяют прибыль внутри рынка. Наиболее сильна конкуренция (оценка 5): приходят новые игроки (МТС, Т1), доля топ-5 снизилась до 36% (форма 31). Наиболее слаба сила потребителей, потому что стоимость переключения высокая (3–6 месяцев, форма 30).

**Абзац 4. Мосты между методами**
Макрофакторы проявляются в отрасли так: рост рынка GenAI (PEST) усиливает силу конкуренции (Портер), потому что все видят ажиотаж. В то же время требования 152-ФЗ (PEST) усиливают силу поставщиков (Портер), потому что заставляют зависеть от российских облаков.

**Абзац 5. SWOT**
Из этого во внешние поля SWOT переходят возможности (O1 — рост GenAI, O3 — уход зарубежных вендоров) и угрозы (T1 — новые игроки, T2 — 152-ФЗ). Сильная сторона (S1 — наличие в реестре) позволяет использовать O3. Слабость (W1 — отсутствие своей LLM) делает опасной угрозу T1.

**Абзац 6. Вывод и задел для п. 2.3**
Рынок привлекателен для узкоспециализированных вендоров при условии фокуса на нише (например, контакт-центры для банков) и непривлекателен для новичков без своей LLM, потому что конкуренция высокая. Поэтому при сравнении игроков на карте рынка критерий «Собственная LLM» получит повышенный вес (40%), а «География» — пониженный.
