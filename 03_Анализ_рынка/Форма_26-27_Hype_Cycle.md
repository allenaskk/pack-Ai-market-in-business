# Формы 26-27. Hype Cycle (Стадии технологий)

| Технология | Фаза | Обоснование |
| :--- | :--- | :--- |
| **Генеративный ИИ (LLM)** | **Пик завышенных ожиданий** | Инвестиции растут (4,5х), но мало промышленных внедрений. |
| **Компьютерное зрение (CV)** | **Склон просвещения** | Есть реальные внедрения (банки, транспорт). |
| **ИИ-агенты** | **Технологический триггер** | Новый тренд, много экспериментов, мало кейсов. |
| **Биометрия** | **Плато продуктивности** | Массовые внедрения (оплата лицом). |
| **Голосовые боты** | **Плато продуктивности** | Стандарт для колл-центров. |

**Вывод:** Генеративный ИИ на пике (ажиотаж), Компьютерное зрение и Биометрия уже приносят реальную пользу.
